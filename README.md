# 🛒 Retail Intelligence & Market Basket Analysis

> End-to-end analytics project on supermarket transaction data: data cleaning, market basket analysis, customer segmentation, product recommendations, and an interactive dashboard.

**Program:** DEPI – Digital Egypt Pioneers Initiative
**Track:** Data Scientist
**Status:** 🚧 In progress (Documentation phase)

---

## 📌 Overview

Retail stores generate large volumes of transaction data but rarely turn it into decisions. This project analyzes supermarket transactions to discover which products are bought together, group customers by behavior, and recommend products, then presents everything in a dashboard for non-technical users.

## 🎯 Objectives

1. Clean and prepare a large, messy transaction dataset.
2. Discover frequent itemsets and association rules (support, confidence, lift).
3. Segment customers (RFM + clustering) and describe each segment.
4. Generate product recommendations from the discovered patterns.
5. Deliver an interactive dashboard.
6. Document the full project.

## ✨ Features

- Data cleaning pipeline with a cleaning log
- Exploratory data analysis (sales, products, time trends)
- Association rule mining (Market Basket Analysis)
- Customer segmentation
- Product recommendations
- Interactive dashboard with filters

## 🗂️ Dataset

Synthetic supermarket transactions (large volume) . The data  contains dirty records (missing values, duplicates, inconsistent formats, outliers) to clean.
